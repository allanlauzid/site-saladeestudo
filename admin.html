Escolha uma skill, descreva o tema do post e gere o texto ou a imagem com o Gemini.

Sem créditos ou deu erro na API? Use a seção de Prompts de emergência abaixo para copiar o prompt e colar direto no Gemini pelo navegador.

Histórico de gerações

Todo texto e imagem gerados aqui ficam salvos automaticamente neste navegador, do mais recente para o mais antigo. Quando o armazenamento local chegar perto do limite, os itens mais antigos são apagados sozinhos aos poucos para abrir espaço.

Skills / Prompts pré-feitos

Modelos de prompt no estilo da empresa. Use {tema} no texto onde o assunto do post deve entrar.

API Keys do Gemini

Ficam salvas só neste navegador (localStorage). Você pode cadastrar várias keys: se a ativa ficar sem créditos, o gerador troca automaticamente para a próxima.

Se a API key ficar sem créditos, copie o prompt e cole direto no Gemini no navegador. Use "Inserir da skill" para carregar o prompt de uma das skills salvas (o placeholder {tema} vira [COLOQUE O TEMA AQUI] para você preencher na mão).
