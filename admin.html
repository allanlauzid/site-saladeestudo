Resolução de exercícios

Gere o PDF de exercícios já resolvidos, pronto para entregar ao aluno.

  1. Clique em ChatGPT ou Claude — o prompt já abre colado no campo de mensagem.
  2. Anexe o PDF, a imagem ou cole o texto com os exercícios a resolver.
  3. Preencha os dados que forem pedidos pelo prompt.
  4. Pronto — o PDF com a resolução sai formatado para entregar ao aluno.

No Gemini o prompt não pode ser aberto já preenchido: clique em Gemini, depois em Copiar prompt — só então o botão do Gemini libera para abrir a página, onde você cola o prompt e segue os mesmos passos acima.
